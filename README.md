## 📌 Project Overview

**SkillSwap** is a responsive web application designed for college and university students to exchange skills peer-to-peer without monetary transactions. Students can list skills they excel at (e.g., Python programming, video editing, calculus, guitar) and search for peers willing to teach skills they want to learn (e.g., graphic design, web development, language learning).

This project is developed as part of **5th Semester Web Development / Academic Coursework**, focused on clean semantic markup, modern styling, and mobile-first responsive design using **HTML5**, **CSS3**, and **Bootstrap 5**.

---

## 🚀 Key Features

- **🏠 Responsive Landing Page**: Hero section with clear call-to-actions, value proposition, and how-it-works workflow.
- **🔍 Skill Directory & Search**: Browse offered and requested skills by categories (Tech, Design, Academics, Languages, Arts) with filter pills and search bar.
- **👤 Student Profiles**: Showcases skills offered, skills needed, college major, bio, badges, and review ratings.
- **🔄 Swap Request System**: Modal dialogs to propose a skill exchange session with date/time, mode (online/offline), and exchange terms.
- **📊 User Dashboard**: Manage active exchanges, pending requests, swap history, and notifications.
- **⭐ Reviews & Ratings**: Peer feedback and rating system to maintain trust and quality within the student community.
- **📱 Fully Responsive Design**: Mobile-friendly navigation, grids, and components powered by Bootstrap 5.

## 💻 Getting Started

### Prerequisites
- Modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).
- Code editor such as [Visual Studio Code](https://code.visualstudio.com/).
- *(Optional)* [Live Server Extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) for VS Code.

### Running Locally
1. Clone or download this project repository to your local machine.
2. Navigate to the project root folder:
   ```bash
   cd "SkillSwap – Student Skill Exchange Platform"
   ```
3. Open `index.html` in your browser:
   - **Option 1**: Double-click `index.html` directly from your file explorer.
   - **Option 2**: Right-click `index.html` in VS Code and select **"Open with Live Server"**.
